Report04

Principles

Principle I

Non-custodial

Keys are made on the user's device. Our software has nothing to hold.

Principle II

Open source

Anyone can read, audit, fork and run the code we publish.

Principle III

Security

Report issues to us privately before publishing them. See 05.

Report05

Security & disclosure

More than $20,000 paid to security researchers since Peanut started.

Please give us the chance to fix an issue before you publish it. That figure is history, not a rate card.

Scope
Peanut app and website, Peanut API, the smart contracts behind Peanut accounts
Report to
Peanut support chat. Start at peanut.me/en/help/security-disclosure
Include
What you found, where, and how to reproduce it
